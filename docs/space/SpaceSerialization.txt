================================================================================
SPACE STORE FILE FORMAT (.jtsf)
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│ HEADER                                                                  │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Magic Number             │ 4 bytes   │ "JTSF" (0x4A 0x54 0x53 0x46)     │
│ Version                  │ 1 byte    │ 0x01                             │
│ Space ID (Most Sig)      │ 8 bytes   │ UUID high 64 bits                │
│ Space ID (Least Sig)     │ 8 bytes   │ UUID low 64 bits                 │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ EXPRESSION STORE                                                        │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Expression Count         │ VarInt    │ Number of expressions            │
│                          │           │                                  │
│ Expression[0]            │ Binary    │ SExpression                      │
│ Expression[1]            │ Binary    │ SExpression                      │
│ ...                      │ ...       │ ...                              │
│ Expression[N-1]          │ Binary    │ SExpression                      │
└──────────────────────────┴──────────────────────────────────────────────┘

================================================================================
SATOM ENCODING
================================================================================

Type Tags:
    0x00 = SSymbol
    0x01 = SExpression
    0x02 = SGrounded<Long>
    0x03 = SGrounded<Double>
    0x04 = SGrounded<String>
    0x05 = SGrounded<Boolean>
    0x06 = SGrounded<Int>

┌─────────────────────────────────────────────────────────────────────────┐
│ SSymbol (0x00)                                                          │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x00                             │
│ Name                     │ String    │ Length (VarInt) + UTF-8 bytes    │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SExpression (0x01)                                                      │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x01                             │
│ Atom Count               │ VarInt    │ Number of atoms                  │
│ Atom[0]                  │ Binary    │ Recursively encoded SAtom        │
│ Atom[1]                  │ Binary    │ Recursively encoded SAtom        │
│ ...                      │ ...       │ ...                              │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SGrounded<Int> (0x06)                                                   │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x06                             │
│ Value                    │ VarInt    │ Integer value                    │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SGrounded<Long> (0x02)                                                  │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x02                             │
│ Value                    │ VarInt    │ Long value (VarInt encoded)      │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SGrounded<Double> (0x03)                                                │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x03                             │
│ Value                    │ 8 bytes   │ IEEE 754 double                  │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SGrounded<String> (0x04)                                                │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x04                             │
│ Value                    │ String    │ Length (VarInt) + UTF-8 bytes    │
└──────────────────────────┴──────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SGrounded<Boolean> (0x05)                                               │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Type Tag                 │ 1 byte    │ 0x05                             │
│ Value                    │ 1 byte    │ 0x00 (false) or 0x01 (true)      │
└──────────────────────────┴──────────────────────────────────────────────┘

================================================================================
VARINT ENCODING
================================================================================

Variable-length integer encoding:
  - Each byte: 7 bits data + 1 continuation bit (MSB)
  - Continuation bit 1 = more bytes follow
  - Continuation bit 0 = last byte
  - Little-endian order

Examples:
    0       → 0x00
    127     → 0x7F
    128     → 0x80 0x01
    255     → 0xFF 0x01
    16383   → 0xFF 0x7F
    16384   → 0x80 0x80 0x01

Byte sizes:
    0-127           1 byte
    128-16,383      2 bytes
    16,384-2M       3 bytes
    2M-268M         4 bytes
    268M-2^32       5 bytes

================================================================================
PACKED BINDING EXAMPLE
================================================================================

Space Store:
  [0]: (foo bar)
  [1]: (foo baz)
  [2]: (outer (inner value))

Pattern: (foo $x)

Variable Schema: ["x"]

Packed Matches:
  Match 0:
    x → PackedBinding(storeIndex=0, atomPath=[1])
        Resolves to: Store[0].atoms[1] = "bar"

  Match 1:
    x → PackedBinding(storeIndex=1, atomPath=[1])
        Resolves to: Store[1].atoms[1] = "baz"

Pattern: (outer (inner $x))

Variable Schema: ["x"]

Packed Matches:
  Match 0:
    x → PackedBinding(storeIndex=2, atomPath=[1, 1])
        Resolves to: Store[2].atoms[1].atoms[1] = "value"

================================================================================
SPACE EFFICIENCY
================================================================================

Traditional Approach (storing actual values):
  Per match: ~60-110 bytes (variable name + SAtom value)
  1000 matches: 60-110 KB

Packed Index Approach:
  Per match: ~3-6 bytes (store index + path)
  1000 matches: 3-6 KB

Reduction: 15-20× smaller
